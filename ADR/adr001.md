@startuml c4-contexto
title MIMETIC - Generación de Historias Clínicas mediante Voz (ADR-001)
skinparam componentStyle rectangle
skinparam packageStyle rectangle

actor "Médico" as Medico

package "SISTEMA MIMETIC" {
  component "Interfaz Web/Móvil" as UI
  component "Servicio de Voz" as Voz
  component "Backend MIMETIC" as Backend
  component "Módulo de Historia Clínica" as HC
  database "Base de Datos" as DB
}

cloud "API de Reconocimiento de Voz" as SpeechAPI

Medico --> UI: Inicia captura de voz
UI --> Voz: Envía audio
Voz --> SpeechAPI: Solicita transcripción
SpeechAPI --> Voz: Devuelve texto
Voz --> Backend: Envía texto
Backend --> HC: Procesa información
HC --> UI: Muestra historia para revisión
UI --> Medico: Presenta resultado
Medico --> UI: Confirma o corrige
UI --> Backend: Envía historia validada
Backend --> HC: Guarda historia
HC --> DB: Persiste información

note right of Voz
Capa de abstracción
para desacoplar el
proveedor de voz.
end note

note right of HC
Validación obligatoria
por parte del médico.
end note
@enduml
